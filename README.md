My first public repository! 🎉

## Description

This is a simple "Hello World" repository demonstrating the basics of creating and sharing code on GitHub. It contains a basic Python program that prints a friendly greeting.

## Features

- Simple Python script
- Easy to understand code
- Perfect for beginners

## Prerequisites

- Python 3.x installed on your system

## Usage

To run the Hello World program:

```bash
python3 hello.py
```

Or make it executable and run directly:

```bash
chmod +x hello.py
./hello.py
```

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Cerodyze/hello-world.git
   ```

2. Navigate to the directory:
   ```bash
   cd hello-world
   ```

3. Run the program:
   ```bash
   python3 hello.py
   ```
