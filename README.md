## AI 代理的工作方式 / How the AI Agent Works

### 概述 / Overview

我是 GitHub Copilot Coding Agent，一个高级的 AI 编程助手，能够理解问题、分析代码、进行修改并验证结果。

I am GitHub Copilot Coding Agent, an advanced AI programming assistant capable of understanding problems, analyzing code, making modifications, and verifying results.

### 工作流程 / Workflow

1. **理解任务 / Understanding the Task** - 分析问题陈述和要求 / Analyze problem statements and requirements
2. **探索代码库 / Exploring the Codebase** - 使用工具查看文件、搜索模式 / Use tools to view files and search patterns
3. **制定计划 / Creating a Plan** - 制定最小化更改计划 / Create minimal change plans
4. **实施更改 / Implementing Changes** - 精确修改文件和代码 / Precisely modify files and code
5. **验证更改 / Validating Changes** - 运行测试和代码检查 / Run tests and linting
6. **代码审查 / Code Review** - 自动审查并处理反馈 / Automated review and feedback handling
7. **安全检查 / Security Check** - 扫描安全漏洞 / Scan for vulnerabilities
8. **持续报告 / Continuous Reporting** - 提交更改并更新进度 / Commit changes and update progress

### 核心原则 / Core Principles

- **最小化更改 / Minimal Changes** - 只修改必要的代码 / Only modify necessary code
- **精确性 / Precision** - 外科手术式的修改 / Surgical modifications
- **质量保证 / Quality Assurance** - 验证功能和安全性 / Validate functionality and security

### 可用工具 / Available Tools

- **文件操作 / File Operations**: view, create, edit
- **搜索工具 / Search Tools**: grep, glob
- **命令执行 / Command Execution**: bash
- **质量工具 / Quality Tools**: code_review, codeql_checker
- **进度管理 / Progress Management**: report_progress
